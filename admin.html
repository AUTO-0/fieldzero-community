CONTROL
ROOM.

Admin sign in

Use the admin account created in Supabase Authentication. Do not share this login.

Player applications

Private applicant information. Approve only players you have reviewed.

Launch mode & public announcements

Keep the Opening Soon notice active while members register. Turn it off after launch. The public registration form remains available in either mode.

Website appearance

Choose a restrained colour theme for the whole public website. Seasonal themes only replace the base theme for dates you approve. No emoji effects or random clip-art pop-ups are used.

Seasonal greetings & campaign calendar

Schedule each campaign for 3–4 days. The start and end dates both count as display days. Only one pop-up can appear at a time; Opening Soon remains highest priority until you turn it off. Religious and cultural greeting campaigns start without a promotional button; keep text dignified and use suitable imagery. Dates can be edited as official calendars change.

Session package prices

These prices update the public Experiences cards. Leave the amount blank for “Custom” or “Coming soon”; use the display label to control that text.

Session & tournament bookings

Private contact details. Approve requests to confirm them; contact players using their supplied number.

Arena calendar requests

Approve a request to mark the time as booked on the public calendar.

Squad challenges & leader registrations

Review challenge requests and contact both team leaders. Notifications are not sent automatically by this static website.

Event registrations

Approve participants so they appear on event detail pages.

Publish match result

Add the result to the event scoreboard after the referee confirms it.

Manage teams

Squads publish once at least one approved player is assigned. Each squad can recruit up to five active players. Edit rank, points, captain and roster here.

Public feedback

Ratings and comments publish immediately. Remove abusive, private or spam content here.

Session gallery & featured pop-up

Upload photos from a particular session. Published photos are visible to all website visitors. Mark selected images as featured to show a one-time pop-up per browser session. Upload only photos you have permission to publish.

Assign players to squads

Only approved active players can be assigned. Each team has a hard limit of five active players.

Operator directory, rankings & deletion

Admin-only directory with name, callsign, rank, WhatsApp/mobile, equipment, preferred play style and squad. Keep this private; contact details are never shown on the public website.

Manage FIELDZERO locations

Add fields as the community expands. Each field has its own address and Google Maps link; event listings and booking requests can be assigned to a field.

Manage published events

Delete events that should no longer appear on the public website. Deleting an event can also remove its registrations and results.

Publish an event

Announce sessions and tournaments on the public website.

Security note: all privileged changes are checked by Supabase Row Level Security. The public website must never contain a service-role key.
